# Writing mode

Use this workflow while drafting or extending definitions, statements,
derivations, or proofs.

1. State the exact target and inventory existing notation, semantic roles,
   scopes, and notation the user has not authorized changing.
2. Write a candidate object's transparent expression first.
3. Apply the necessity criteria in `references/principles.md` as routed by
   `SKILL.md` before assigning a new symbol.
4. Require every intermediate space, operator, lemma, and parameter to perform
   a clear proof function.
5. Retain every necessary definition, hypothesis check, intermediate step, and
   conclusion bridge.
6. Re-audit the completed passage for notation burden and conflicts.

Check that every new symbol is defined before use and justified; one-use aliases
and wrapper chains are absent; synonymous notation is merged or explained; no
glyph has incompatible roles; and abbreviations do not hide constraints needed
at the current step.

When semantic typography or differential spacing is involved, also follow
`references/semantic-typography.md` as routed by `SKILL.md`.

## Completion report

Report every nonstandard symbol introduced and its justification, conflicts and
semantic-typography decisions, aliases deliberately left expanded, and any
tradeoff requiring user judgment.
