# Legacy Material

This directory contains archived snapshots and historical notes retained for
reference. They are not part of the active manuscript.

- `draft-2026-07-24/` is the archived snapshot of the former root-level
  `draft/` directory. Its name records the directory's last-modified date.
  Treat this snapshot as immutable and do not edit files inside it.
- `notes/` contains earlier working notes organized by topic.

New manuscript work belongs in the repository-root `draft/` directory.
