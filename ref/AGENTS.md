# Reference guidance

This file applies under `ref/`; the repository-root `AGENTS.md` also applies.

* When adding, renaming, or removing a reference, update both `README.md` and
  `reference.bib`; keep entries alphabetized by first-author surname, then year,
  and insert new references in the correct position rather than appending them.
* Verify bibliographic metadata and do not guess missing fields.
* Keep index entries concise: record the reference identity, topic, and brief
  project relevance rather than copying abstracts or long excerpts.
* Store PDF files, books, translation projects, and other reference data in the
  sibling directory `../TEP_ref/`. Access them inside the repository through
  `ref/ref_data/`, and write catalog paths relative to `ref/`, beginning with
  `ref_data/`.
* Do not add reference documents to Git; only `README.md`, `reference.bib`, and
  this `AGENTS.md` are tracked under `ref/`.
