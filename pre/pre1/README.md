# pre1 Beamer Report

This directory contains a concise English beamer report on the transmission-eigenvalue / Bloch-mode formulation for periodic waveguides and line-defect scattering.

Compile from this directory with one of:

```sh
latexmk -pdf pre1.tex
```

or:

```sh
pdflatex pre1.tex
pdflatex pre1.tex
```

The slides include explicit placeholders for numerical figures. They do not claim any unvalidated numerical results.
