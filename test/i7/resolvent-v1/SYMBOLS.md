# I7.4 symbol ledger

Source authority is the frozen I7.4 task contract, the reviewed I7 matching
conventions in `design-7-3a.md`, and I6 formulas T9--T10/F14/N9.

| Code name | Kind and scope | Mathematical meaning, type, shape, units | Defined / consumed |
|---|---|---|---|
| `model.khat`, `model.beta`, `model.d`, `model.L` | frozen scalars | $\widehat k$, quasi-period $\beta$, transverse period $d$, cell length $L$ | MATLAB entry / all stages |
| `model.axes` | frozen geometry | ellipse semiaxes $[a,b]=[0.25,0.16]$ | curve and collar calculations |
| `model.rho_center`, `model.rho_lead`, `model.rho_exterior` | material scalars | center, lead, and background relative parameters | cell maps / scalar report |
| `q` | physical port state | normalized $[a^L;b^R]\in\mathbb C^{2K}$ with the saved phase convention; exported at top level for the safe-disk audit | matching SVD / every raw-field component |
| `center_density` | frozen physical BIE density | exact-dyadic interpretation of the saved binary64 samples generated by $\operatorname{fl}(H_La^L+H_Rb^R)=[\tau;\zeta]$, $\zeta=-\sigma$ | center cell map / ellipse layer and safe-disk actions |
| `Zplus`, `Zminus` | QZ bases | qualified stable right/left lead state subspaces, $2K\times K$ | lead pencil / propagation |
| `Pplus`, `Pminus` | propagation matrices | full stable-subspace cell propagation, $K\times K$ | lead material sum / scalar audit |
| `Dplus`, `Dminus` | trace maps | sums of the two port blocks of each QZ basis, $K\times K$ | propagation coordinates |
| `cplus`, `cminus` | lead coordinates | nearest-cell coordinates determined by the center trace | lead material sum |
| `Gplus`, `Gminus` | cell-input maps | $[A_+;B_+P_+]$ and $[A_-P_-;B_-]$, mapping propagation coordinates to each cell's incoming port state | lead material and wall sums |
| `density_scale` | boundary coordinate map | $D=\operatorname{diag}\sqrt{h[v;v]}$ formed from the same curve matrix $C$ passed to `construct_A_QP` | raw boundary action |
| `A_scaled`, `A_raw` | boundary operators | public $A_s=DA_{raw}D^{-1}$ and the physical-coordinate action $A_{raw}=D^{-1}A_sD$ | material jumps and audit |
| `density_map` | fixed physical density map | original 256-node $[H_L,H_R]$ or its trigonometric interpolation; it is never re-solved on the 512-node audit grid | material action |
| `signed_value_action` | raw jump map | $a=u_{out}-u_{in}$ sampled on a physical material curve | material action / norm |
| `signed_normal_action` | raw jump map | $j=\partial_\nu u_{in}-\partial_\nu u_{out}$ with the whole sign applied before modulus | material action / norm |
| `epsilon_boundary` | numerical scalar | $\sqrt{\|j\|^2+\|a\|^2/d^2}$ from physical samples | MATLAB result / conditional F14 |
| `mass.cone_candidate` | numerical scalar | sampled safe-disk analogue of the N9 lower-bound expression | MATLAB result / conditional F14 |
| `U_lower_candidate` | data field | alias of `mass.cone_candidate`; explicitly not a certified lower endpoint | JSON / scalar report |
| `same_field_mass_certificate` | Arb audit record | Rayleigh-series safe-disk point lower, gradient upper, and certified $U_{under}$ for the frozen $q,\eta_c$ | scalar report only |
| `curvature_max`, `reach_lower` | ellipse geometry | $a/b^2$ and $b^2/a$ | geometry gates / scalar report |
| `structure` | status record | analytic object flags; false quasi-periodicity prevents certification upgrade | JSON / scalar report |
| `wall_tail_data` | scalar-audit inputs | binary64 samples of the center/lead densities and full $G_\pm,c_\pm$ maps for the separate $|m|>48$ wall bound | numerical-input JSON / Arb report |
| `audit` | fresh verification record | independent matching, propagation, raw-action, component, and JSON-transport defects with threshold $10^{-11}$ | `audit_i7_resolvent.m` / formal run output |
