## 冻结方法

- 原生曲边P2，左右各6胞元；中心未缩放星形材料4，左右不同三瓣形材料17，背景1。
- $k_h=1.5584630910866906$，$\mu_h=k_hk_h$，$s=\mu_h$。
- 每元RT2有9个外法向Legendre边矩及6个内部矩。边矩Gauss12、体矩Duffy8。
- 局部逆Piola插值梯度，然后以全局方向/奇偶号做一次共享边平均；上下以同一
  $e_y$ 法向及相位反拉平均。人工端矩保持不变，不强制零。
- 真实材料曲线各8192段，解析二阶导数余量管；参考子片最多四分6层。
  未确定片保留完整离散材料集合 `{1,4,17}`，不扩成全域材料区间。
- 正式积分Duffy10，Duffy8为同一通量的积分诊断；端Gauss20，Gauss16为诊断。
  这些是普通算术，差值及未分类片的求积包络不是可靠区间证书。
- 直接先计算 $\nabla u-p$ 和 $\operatorname{div}p+\mu_h\rho u$ 再平方。
  另存有限通量表示、原生体缺陷、平均lifting、真实/网格材料失配分项。
- 预先参考尺度 $R\leq0.01$、$10^{-4}$；bulk积分包络宽度目标 $1.8\times10^{-7}$，
  各端平方范数阶数差目标 $10^{-10}$，未达仍如实交付。

互斥计时包括输入检查、通量构造、材料分类、主积分、积分诊断、端积分、标量及保存；
总MATLAB函数时间与监控进程墙钟另列，不重复相加。
全部生成物在被忽略的 `output/` 内，含失败记录、MAT、原始二进制数组及JSON。

### 积分与资格诊断

- 原生场端值、上下相位、恢复约束矩阵差均为0；全参考Jacobian最小值
  $2.08794997698\times10^{-5}$。9750元、14793边、336外边，连通圆盘拓扑和唯一矩形边界。
- RT2对偶恒等式缺陷 $1.10\times10^{-13}$；仿射P2梯度／散度复现约
  $1.20\times10^{-14}$／$2.93\times10^{-14}$。内部矩与人工端矩改变均为0。
  全边物理法向跳跃最大 $3.37\times10^{-13}$，上下准周期法向差 $1.58\times10^{-15}$。
- 分类783870个参考叶片；深度6仍有260971个未确定片，物理面积数值0.0155922841。
  它们保留全 `{1,4,17}` 集合，未被置零或当作已确定材料。
- 未确定片材料求积包络给 $M_s^2$ 宽度0.0602224885，**未达到**预设
  $1.8\times10^{-7}$目标。按此宽度的保守普通求积诊断给 $R$ 范围
  [1.5709001853,1.8644133841]；这不是严格上下界。
- Q8/Q10质量绝对差 $2.07938\times10^{-7}$，加权体缺陷平方差
  $3.06272\times10^{-5}$；两端16/20阶差均低于 $4.1\times10^{-20}$。
  积分阶数差不证明积分误差界；矩舍入及曲线常数也未经过有向舍入认证。
- 轻量后验核对全部中心已分类片中点及未知片Q10实际点共2,095,167个：
  射线求根归一cross最大 $7.57\times10^{-16}$、dot最小0.9999999999999996。
  单元Bernstein盒未越相应胞元（最大舍入量 $2.67\times10^{-15}$），曲线管距胞元界
  至少0.1399998117，支持逐胞元几何剪枝。

### 解释及下一步边界

当前 $R$ 约为0.01参考尺度的171.98倍、$10^{-4}$的17197.79倍，**不具备这两个尺度的
实用分辨能力**。该结论只说明本显式通量估计的分辨力，不证明候选实际误差大。
通量表示误差很小，平均lifting散度较大；在未来另获授权时，可先研究降低通量平衡
缺陷的收益，同时保留原生体缺陷与人工端限制。当前积分未认证也未达预算，但阶数差
及材料包络诊断未改变“不达0.01”的数值观察。不得把后处理精化视作原生场误差改进。

独立审查见同阶段 `review-9-4a.md`；本目录不自行将实现自检称为独审。
