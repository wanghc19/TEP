# I9.2：固定材料4候选的 FMM 谱距离数值估计

实现依据 [design-9-2a](../../../research/projects/eig-apost/implementation/i9/design-9-2a.md)。
本目录从零重求一个物理场，完成 I6→I7→I8 resolvent 直接跳跃公式；不搜索、不计算第二档评价、
不运行直接法对照。结果是 `UNCERTIFIED_RNUM`，不是可靠上界、残差范数或实际特征值误差。

## 唯一配置与数值路径

`estimate_i9_config.m` 集中定义全部科学参数。固定
$k_0=1.5584378941820909$、$\beta=0.5$、$d=L=1$；中心公共五瓣星形的外层
`star_scale=1`，公共内部0.2保持，面积 $0.0618\pi$、相对介电常数4、内部波数 $2k_0$。
负/正侧分别为 $a=0.12/0.20$ 三瓣形，同一全局朝向，各自面积 $0.04\pi$、介电常数17。

- 构场：中心512、负侧256、正侧256；$M=48$、$K=97$；
  `nside=ntop=160,nproxy=80,mpw=32,H=1.1,proxy_dist=0.2`。
- 唯一评价：材料界面768、纵向人工墙768、周期接缝诊断768；每侧40个有限胞元及各自尾项。
- 质量：背景圆盘圆心 $(0,3/8)$、半径 $1/16$，32×64、角度半格移位。
  `U_num` 是该局部背景圆盘的质量范数数值评价，不是全波导积分。
- FMM请求容差 $10^{-12}$；MATLAB/OpenMP均11线程，`OMP_DYNAMIC=FALSE`。
- `wall_batch=64`、`mass_batch=32` 是物理目标批量。相应pairmat最多49,152/24,576个源—目标差位置，
  不是物理目标数；单目标中心值按已验证方法复制目标后只取首行。

`estimate_i9_numeric.m` 只迁移 I8 pipeline 的谱距离必要helper，并以 I9.1 独立lead路径构场。
负侧用逆向pencil、正侧用正向pencil；物理密度映射、传播 $P_\pm$、输入 $G_\pm c_\pm$、
材料动作、墙图、有限前缀及观察比率尾项全部分开，不镜像、不共轭、不乘2。
一次归一化后的匹配向量固定，`center_density` 固定；768节点只用 `interpft` 插值，不重求密度。

FMM用于pairmat的光滑proxy势/梯度/Hessian：构场、768材料矩阵、纵向墙、周期接缝诊断和质量评价。
自由空间、奇异核、Kress、跳跃项仍由公共原实现处理。公共 `construct_A_QP` 的regular diagonal
光滑proxy仍直接求值；没有修改公共函数或声称所有核都由FMM替代。

周期方向属于exact-QP数学场：上下接缝的理论跳跃为零。显式评价top−$e^{i\beta d}$bottom
及同向导数差作为FMM/浮点评价一致性诊断保存，**不加入** `epsilon_num`，不改变原迹常数的
`overlap_count=1`。这不是省略必要尾项；材料和纵向人工墙尾项均独立评价并检查可用性。

$$
\mu_{\rm num}=k_0^2,\quad
\epsilon_{\rm num}^2=E_n+E_v/d^2,\quad
Q_{\rm num}=C_{\rm num}\epsilon_{\rm num},\quad
R_{\rm num}=\frac{2\mu_{\rm num}Q_{\rm num}}{U_{\rm num}-Q_{\rm num}}.
$$

三条真实曲线分别用4096/8192点核查面积、速度、法向、曲率、局部弧段、远弦、offset collar、
人工墙及周期副本间距。全局曲率取三者最大值，材料极值取背景及三种区域的最小/最大值。
新圆盘下缘0.3125大于星形解析上界0.26；不使用旧横向圆盘。

## 从空 output 复现

MATLAB函数仅通过普通path解析本目录、公共package与已安装FMM2D；没有读取旧实验入口或历史数据。
下列路径由启动者显式提供，数值源码不探测目录层级；`FMM_ROOT`是已有官方FMM2D的matlab目录。

```sh
python3 run_estimate.py --mode config --output output/attempt-1/setup-01 \
  --package-root "$PACKAGE_ROOT" --fmm-root "$FMM_ROOT" --matlab "$MATLAB_BIN"
python3 run_estimate.py --mode run --output output/attempt-1/run-01 \
  --config output/attempt-1/setup-01/config.json \
  --package-root "$PACKAGE_ROOT" --fmm-root "$FMM_ROOT" --matlab "$MATLAB_BIN"
python3 summarize_estimate.py output/attempt-1/run-01
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 \
  "$NUMPY_PYTHON" audit_estimate.py output/attempt-1/run-01
```

`NUMPY_PYTHON`须指向已有NumPy环境，不安装新依赖。审计只重组本次输出，不参与数值入口。
`--output`必须是新run目录，避免覆盖。已有attempt完成后改变科学合同时按仓库规则选择新attempt；
同一方法操作性修复仍用同attempt的下一run。监控拒绝已有MATLAB，1秒采样进程树，
40分钟/3,000,000,000 bytes硬限，异常退出清理子进程。若需要串行额外批次，传
`--prior-status`继承原预算起点，包含批间等待；本次只有一个科学批次。
