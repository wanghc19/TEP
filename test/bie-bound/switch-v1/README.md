# switch-v1: MFS wrap switch-line defect, version 1

MFS = method of fundamental solutions；BIE = boundary integral equation；FMM = fast multipole method；QP = quasi-periodic；Q5 为圆盘质量公式编号；RSS = resident set size。所有数字均为浮点估计，Proposition S 按待审提案使用。

## 固定场与方法

复制 budget-v1 的构场、密度插值、传播和点评价代码，模型、k0、512/256 原生密度和代理设置不变。构场一次，不读旧输出。柱内使用自由空间核，因此实际 switch 项只来自三个背景分片；另列 rho=4/17 代理核作为经理测量的对照，不加入预算。存储密度记为 tau、zeta，按实际代码使用 `-tau*(nx*Gx+ny*Gy)-zeta*G`，不再因第二密度名称翻转符号。

直接评价 X=±d/2 两支，给出物理坐标 G、Gx、Gy、Hxx、Hxy、Hyy 的跳跃。对一维 Y 表用 8193 点及其隔点 4097 表作插值比较；切线方向用128/256阶 Gauss，源方向用原生、1536、3072节点，不重求密度。几何先核对切换线是否与柱相交；若所有源的切换高度均在柱外，则背景裁剪段恰为整个胞元 x 区间，柱内段为空。每个源先对40个引线胞元的平方求和，按旧末项比率法补尾，再开方、沿源弧长积分。分别记录两种密度及组合，主 Q_sw 用组合。

## 运行前预估

run-001：构场、单盘复现、直接核表、三源档、加倍核表／线求积及真实代码路径核对，预计 180–600 秒，峰值 1.5–2.2 GiB；最多 1800/2400 秒、3 GiB，11线程，OMP_DYNAMIC=FALSE。表插值将数十万目标对的代理 Bessel 计算变成一维查表；误差由网格加倍和直接离网点评价核对。没有改变固定代理系数。

(f) 6144源墙暂不随首轮启动：保守峰值预估为旧3072档1.43 GiB的两倍再加0.25 GiB瞬态余量，约3.11 GiB，超过硬限。此数为保守预估，并非实测；(a)–(e) 使用分块积分，不需要这两个大层矩阵。
