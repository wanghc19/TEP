# I5 reliable all-zero-center residual-numerator fallback

This experiment evaluates a deliberately coarse residual-numerator majorant in
the exact-arithmetic, roundoff-excluded model.  Every retained material and wall
action, including the local identity, has center zero.  Complete action bounds
are radii, so no finite special-function value is used as a governing center.

The builder has explicit, portable input and output paths:

```matlab
build_residual_numerator_input_v4(artifact_path, curve_contract_path, input_path);
residual_numerator_v4(input_path, output_path);
```

It loads only the frozen I3 artifact and the accepted curve contract.  The
runtime evaluator loads only the resulting self-contained input MAT file.  No
entry reads Markdown, Git state, repository-relative paths, or historical
experiment outputs.

The frozen `wall_input_unit_512` trace is included phase-free in each retained
wall-value row.  Its audited support is exactly the half-open range
`-256:255`; direct-input coefficients outside that range are zero by this
finite-support contract.  The wall-density action and complete
positive-distance circle-action radius are separate addends and are each
included once.

The governing bound path uses only rational upper and lower constructions:

- `PI_LO=3`, `PI_UP=22/7`;
- `ABS_SHARP(z)=abs(real(z))+abs(imag(z))`;
- finite Newton upper and residual lower bounds for positive square roots;
- a finite exponential series plus a geometric remainder for growth, and the
  reciprocal of a positive exponential partial sum for decay; non-finite
  partial sums fail closed, while a positive `1e-100` floor prevents a true
  positive tail from disappearing through underflow;
- `LOGABS_UP(x)=x+1/x` and `TANH_LO(x)=x/(1+x)`;
- factorial recurrences and entrywise induced matrix one-norms.

Consequently the governing path does not call `pi`, `sqrt`, `exp`, `log`,
`gammaln`, trigonometric or hyperbolic functions, `norm`, `fft`, or a special
function library.  The current circle is only a geometry certificate for the
shape-general residual inequalities; no circular Fourier/Bessel
diagonalization is used.

The local implementation is split in two.  `LOCAL_circle_KR15_bounds` is
explicitly a current-circle adapter that produces density-inclusive `H_q`,
`Q2`, and ownership fields.  The generic `LOCAL_local_certificate` consumer
reads that certificate interface plus the boundary-length normalization.  The
adapter is not claimed to be a general-shape generator.

All side sequences use a block-power certificate from cell index zero onward.
There is no retained-cell/low-cell split.  Retained local bounds contain the
identity exactly once, while the disjoint generic real-variable Fourier tail
contains the same identity through its density-inclusive second derivative
constant.  The density constants are never multiplied a second time.

The attempt-2 cutoff is selected from the predeclared finite schedule
`[256,1024,4096,16384,65536]`.  A failed tolerance allocation selects the last
finite candidate and is reported as a tightness failure; it does not invalidate
a finite theorem upper bound.  Ordinary floating-point roundoff remains
excluded, so every result is labelled `NON_CERTIFIED_ROUNDOFF_EXCLUDED`.

Attempt 2 keeps the same zero-center theorem and changes only its retained-mode
corollary.  For each retained mode it takes the minimum of the whole-action
radius and the corresponding certified algebraic or strip-decay coefficient
radius, separately for local, regular-image, and off-surface actions.  The
three selected component radii are then added before applying the material or
lifting weight once.  Positive strip powers are generated by one `O(L)`
recurrence.  High-mode tail ownership is unchanged.

The first scientific attempt belongs under `output/attempt-1/`.  Planned wall
time is at most 8 minutes and planned peak memory is at most 1.4 GiB, below the
30-minute and 2-GiB experiment limits.  MATLAB must not be run before the
independent pre-run code review authorizes the exact command.

The create-once run names are `result-run-01.mat`, `run-01-log.txt`,
`resource-run-01.txt`, and `audit-run-01.txt`.  The result is structurally
reliable only when every fail-closed gate passes.  A failed tail-tolerance gate
changes the status to a tightness failure but does not suppress a finite
majorant.

## Attempt records

Attempt 1 run 03 completed the coarse fallback with its then-current
structural gates passing and the tightness allocation failing.  It selected
`L=256` and reported
`B_Gamma_pm=1.5258789063950686e-05`,
`B_Upsilon=84359854948.513657`,
`B_lift=48405666247769712`, and
`M=48405750607624664`.  The run took 11.77 seconds with maximum resident set
size 826,458,112 bytes.  Runs 01 and 02 were same-attempt operational failures
before a scientific result; run 03 is the canonical attempt-1 result.  Later
post-run review withdrew the complete reliability claim because the wall
owner still used historical finite actions without their evaluation errors.

Attempt 2 used `output/attempt-2/`, 64 Newton upper-root iterations, and the
mode-dependent radii described above.  Run 01 completed in 12.48 seconds with
maximum resident set size 805,175,296 bytes.  It selected `L=65536` and gave
`B_Gamma_pm=2.5769594543501116e-10`,
`B_Upsilon=71520151.044302881`,
`B_lift=478442999.20147043`, and
`M=549963150.24577332`.  These are conditional complete-numerator diagnostics
for the same wall-owner reason; the material-only mode-dependent computation
is not affected by that correction.

Attempt 3 keeps the attempt-2 material estimator and replaces only the wall
owner.  The builder reconstructs every zero-centered normal and value radius
directly from `q_center`, the frozen $G_\pm/D_\pm/P_\pm/c_\pm$ data,
the exact finite shared-wall input map, the frozen wall-density rows, and the
positive-distance curve bound.  It does not read `raw_maps.Jplus/Jminus`, the
stored center wall jumps, or the stored center value mismatches in any
governing calculation.  The shared-wall map is checked against the exact
finite embedding of orders $-48{:}48$ in the half-open wall range
$-256{:}255$.  Wall support is independent of the material cutoff $L$: every
frozen wall row is included, order $+256$ is curve-only, and the remaining
two-sided analytic tail starts at absolute order $257$.  Thus the three wall
index sets are disjoint.  The normal action includes the direct half jumps and
curve action but no Dirichlet input; the value action combines the shared
input, flat action, and curve radius within each collar before squaring.  Left
and right collars remain separate.

The exact shared-wall embedding is accepted only when MATLAB `isequal` holds.
The stored `Gplus` and `Gminus` matrices enter the side-sequence upper bound
directly.  Their residual against the displayed block formulas is persisted as
a finite semantic diagnostic only; no approximate matrix equality authorizes
the governing bound.
