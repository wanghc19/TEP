# 界面 S 证书加速探针

accel = acceleration（加速）；v1/v2 = 版本号；PM = polynomial model（含统一余项的多项式模型）；FEM = finite element method；DtN = Dirichlet-to-Neumann；RT = Raviart–Thomas；qj = Goerisch 量 q 和 J；RSS = resident set size；JSON = JavaScript Object Notation；CSV = comma-separated values；Q16/Q24 = 16/24 阶求积。I9 为旧实验编号；poly2 = 二元 polynomial（多项式）；stats = statistics（统计）；RT3 为三阶 Raviart–Thomas。

## 目的与结论

**严格的“三模板分别至少 3 倍”判据未通过。** 最佳已测设置为容差 ×1000、乘积次数 12、级数 16、薄层初始 1 面板、逆猜测迭代 6 次；左／中／右加速 2.37／6.79／2.71 倍，S 超额分别 0.1995%／4.5678%／0.4416%。总界面时间从 461.388 降至 152.155 秒（3.03 倍）。结果处于有明显收益、逐模板尚未达标的区间，尚无全参数不可行结论。

## 方法与计算边界

复制 qj-cert-v2 所需 MATLAB 文件到本目录，旧目录保持只读。每个进程从相同模型重建一次 P3 场、通量和 v1 证书，随后在内存中复用；没有每设置重新生成场，也没有保存大场缓存。轮次变化和新增 profiler/计时操作只在本目录。阶段计时由 `accel_probe.m`（带 profiler）、`accel_sweep.m`（干净计时进程）、`accel_iterations.m`（唯一追加迭代设置）输出。

默认每元素容差为 1e-13/(3×640)=5.208333333333334e-17；“预算容差”是 1.9e-12/640，即默认的 57 倍。除明确标出的参数外，默认次数 12、级数 16、薄层 4 面板、逆猜测 18 次。次数和级数单参数行以预算容差行为参照。乘积丢弃项、倒数和三角级数余项仍全部计入；细分深度与所有有效性检查未改。对降低次数，增加的余项触发更多细分，因而耗时反升；级数降阶仅略有收益。薄层 1 面板已试最少初始面板，未追加 2 面板的中间设置。

仅用原四类旋钮，最好设置是 ×1000＋1 面板：左／中／右 79.880／29.721／78.447 秒，合计 188.049 秒。profiling 指向固定 18 次逆猜测迭代后，只追加一次 6 次迭代。该循环只生成多项式猜测；末次缺陷 `||B(F(guess)-X)||/(1-kappa)`、猜测所在立方体和共同单射域检查独立给出误差，全部保留，因此减少猜测迭代未更改证书公式。默认仍为 18 次；`inverse_iteration_count.m` 只改变这一计算预算。中心上界变化 1.3964e-17，面板数未增加。此组后停止，无进一步优化。

## 对整条流水线的含义

固定其他成本，用旧 MATLAB 内部总计 698.135 秒扣除旧界面 461.388 秒、加新界面 152.155 秒，得到 **388.90 秒**；这是估计，未重跑整条可靠积分流水线。总 S 上界 3.586774161826e-11，Q16 为 3.493453809109e-11，超额 9.332035e-13（2.6713%）。按 9.95 敏感度，S 单项相对 Q16 增宽 9.285375e-12（旧宽度的 0.2081%）；相对旧证书增加 0.1985%。

薄层循环同时给质量偏差界：减板后合计由 6.80236e-12 升至 8.33106e-11。若把新质量界一并代入同一四角公式，标量重组宽度为 4.554474131168718e-9，相对原记录 4.4623318373737675e-9 增加 2.0649%；所以整个区间的增宽应采用约 2.06%，而非只报 S 的约 0.20%。这项重组沿用已算出的 E、公共 S 和质量修正项，未另做全流程运行，舍入仍排除。

仍需保留的全流程非界面部分约 236.75 秒；本次前置实测主要是精确通量转换及两阶积分清单 80.76 秒、通量求解和浮点检查 49.20 秒、v1 证书 42.56 秒。最佳引线仍各需 640 个光滑元素和 320 个薄层面板，并逐一处理 13 个胞元的场与通量。6 次迭代后左／右光滑部分仍为 44.81／43.95 秒，级数总计各仅约 4.38／4.35 秒；余下主要工作在每面板的模型及逐胞元 PM 运算。引线内部未另开 profiler，未精确分离这两项。

- `write_report.py` 只从已有标量输出生成本 README 和指定研究笔记。四角 Python 算式已用旧证书输入复现原端点与宽度，差为 0；验证记录见 run-003/postprocessing-validation.json。
