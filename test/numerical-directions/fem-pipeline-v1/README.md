# FEM 单进程流水线

FEM = finite element method（有限元法）；P2/P3 = 二次/三次单元；RT3 = Raviart–Thomas 三阶通量；DtN = Dirichlet-to-Neumann；RSS = resident set size（常驻内存）。`fem_i9_*` 保留 I9.3（实现阶段 9.3）命名；JSON = JavaScript Object Notation；CSV = comma-separated values；`v1` 为版本 1。BIE = boundary integral equation（边界积分方程）。

## 目的

**从给定窗口到已核查的 P3/RT3 区间，同一个 MATLAB 进程共 119.397907 秒，峰值 2.038391 GiB。** 推荐宽度为 $4.6959526630215774\times10^{-9}$，包含给定 BIE 数值参考。仅运行一次，所有规定的数值检查通过。[汇总](output/run-001/summary.json)、[监控](output/run-001/monitor.json)。

## 起点与边界

唯一外部科学输入是窗口 `[1.4509999999999998,2.2490000000000001]`；模型固定在源码：$\beta=0.5$，周期和条带宽度均为 1，背景／中心／引线材料为 1／4／17，中心星形、两侧半径 0.2 的三叶形参数分别为 0.12 和 0.20。共享的上游能隙探索 28.40966425 秒不重跑、不计入本次时间。[历史账目](../../i9/search-v1/README.md)。

- P2：复制 I9.3 的 13 胞元有限区域，背景每胞元 12 等分、界面 80 段、8 阶积分；平方频率窗口三等分中点为三个移位，每移位取 12 Ritz 对。过滤、去重、随机种子 193 均保持。保留全部 36 条原始模态记录。
- P3：唯一合格候选直接在内存中传给 `direct_native('generate',k_start,...)`。重新生成 g48 三模板（48 等分、界面 320 段），保留 v3 的真实材料修正、DtN 局部求根和括区增长规则。由新网格直接组装模板元数据，替代旧版从 `native.mat` 读取模板的步骤；数值场和源矩文件均不读取。
- Goerisch：保持 v3 的直接 P3 场、余弦截断、$[-13.5,13.5]\times[-0.5,0.5]$ 通量盒、解析曲线拟合、稳定 RT3 基和逐点泛函。$\gamma=1$，谱隙端点为 $1.3174^2,2.1875^2$。主／核查积分阶为 16／24，材料修正阶为 10／16。408 批主场值在准备、组装和泛函中复用；核查使用不同积分点，不重新求根或求通量。

计时含启动、新网格、宽窗搜索、P3 全部求根和引线计算、场恢复、Goerisch 计算、所有检查、输出及退出。11 MATLAB/OpenMP 线程，`OMP_DYNAMIC=FALSE`。所需 MATLAB 函数复制到本目录后修改，旧实验代码和输出保持原样；`goerisch_fitted_geometry.m` 沿用原解析拟合助手。

## 复现命令

在仓库根目录执行，启动器调用原 `diagnostics-v1/monitor.py` 和 MATLAB R2023b：

```sh
python3 test/numerical-directions/fem-pipeline-v1/launch_pipeline.py --window 1.4509999999999998 2.2490000000000001 --output test/numerical-directions/fem-pipeline-v1/output/run-001
python3 test/numerical-directions/fem-pipeline-v1/summarize_pipeline.py test/numerical-directions/fem-pipeline-v1/output/run-001
```

再次运行须用新编号。`window_pipeline.m` 是单进程入口，`validation_values.m` 只提供解算后的比较值；`summarize_pipeline.py` 独立重算端点、宽度和计时，不调用科学求解器。实际 MATLAB 命令见 [command.json](output/run-001/command.json)。

启动前已记录完整运行预计 120–300 秒、峰值 2.2–2.7 GiB，包含 24 阶核查。本次实际耗时略低于预计下端。监控软／硬时间为 30／40 分钟、硬内存 3 GiB；本阶段累计监控计算为 119.397907 秒。只保存小型标量、CSV 和日志，不保存场、矩阵或 MAT 文件。

## 与 BIE 成本记录的对照

以同一给定窗口、无先验候选为起点，两边均使用 11 线程。历史数字来自 [I9.1 搜索账目](../../i9/search-v1/README.md) 和 [I9.2 评价账目](../../i9/estimate-v1/README.md)。

| 路线 | 窗口到结果的已记录时间 | 输出宽度，$\mu$ 单位 | 内存 |
|---|---:|---:|---|
| BIE 历史阶段之和 | 搜索 553.862367 + 配置 19.932651 + 评价 96.084137 = **669.879154 秒** | 约 $1.549\times10^{-9}$（两倍 $R_{\rm num}=7.745852555568109\times10^{-10}$），误差估计 | I9.1 科学进程 1.423 GB；I9.2 配置 0.789 GB、评价 1.389 GB；非独立候选阶段峰值 |
| 本次 FEM 单进程 | **119.397907 秒**，含全部检查及启停 | $4.6959526630215774\times10^{-9}$ | **2.038391 GiB**，整进程 |

这两个记录的时间比为 5.610477。BIE 的 553.862367 秒是粗搜、细搜和新鲜确认之和，复用了共有 gap 阶段的引线缓存，未含 I9.1 的全部启动、调度和其余检查时间；FEM 本次重新构造所有 FEM 模板，并完整计入进程启停和附加积分检查。因此这里给出历史阶段成本与本次完整流水线的对照，不称为同一输出精度、同一检查负担的算法加速比。共有上游探索两边均另列。

## 限制

BIE 输出是无保证的误差估计；FEM 区间沿用 (H) 和尚未认证的能隙端点，当前为普通浮点计算。P2 搜索提供唯一筛选候选，未认证窗口内谱点个数。该区别影响保证形式和最终宽度，不能由成本比较消除。本阶段已完成所要求的流水线和检查，没有待补的数值运行。
