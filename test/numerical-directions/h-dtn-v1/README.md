# h-dtn-v1：DtN certificate for the isolation hypothesis

`h-dtn` 指隔离假设 $(H)$ 的 Dirichlet-to-Neumann（DtN）证书部分。

## 目的

两侧已得到 $33\times33$ 全迹下界矩阵，包含显式积分与无穷引线余项，排除舍入。最终残差罚项均低于 $4\times10^{-4}$；数值及矩阵分别见下表与 `left-certificate.json`、`right-certificate.json`。

## 起点与输入

$\lambda=5.6169$，$\alpha_-=1.7424$。h-cert-v1 排除了两种纯引线的表面态，并给出半引线在 $[1.7424,2.375^2)$ 上无谱。因此
$$K_+=1+(5.6169+1)/(2.375^2-5.6169)=279.899894626.$$
公式值为 $279.899894625925$，代码使用上面的向上取值。$d_-\ge5.6169-1.7424=3.8745$，$K_-$ 公式值为 $0.707807459027$；采用更宽的 $0.70782$。

物理端口为 $-1/2,+1/2$。左侧材料 $a=0.12$，右侧 $a=0.20$；引线胞以整数为中心。三叶形为 $c(\theta)=R(1+a\cos3\theta)(\cos\theta,\sin\theta)$，$R=0.2/\sqrt{1+a^2/2}$，夹杂密度17、背景1。`dtn_native.m` 的原始 `LOCAL_curve` 与 `fem-pipeline-v1/direct_native.m` 相同。左侧内向坐标 $\xi=1/2-X$，右侧 $\xi=X+1/2$，所有积分仍在原物理胞坐标 $X$ 上进行，夹杂不作反射替换。

场及端点代码复制自 fem-pipeline-v1；拟合映射及拓扑来自 gap-ends-v1。整数 RT3（Raviart–Thomas，次数3）参考基另从 qj-cert-v2 复制。h-cert-v1 只提供预解式常数及几何核对输入。本实验采用单胞拟合 P4（次数4）场与 RT3 通量，避免长截断域；离散传递矩阵只选择试探场，其误差由真几何上的残差控制。

## 低频场与通量

低 Fourier 块为 $|i|\le5$，共11列。第一胞用 P4 单胞调和场加端口修正
$$u_i=u_{h,i}+\chi(\xi)e^{-\tau\xi}(g_i-g_{h,i}),\quad \chi=1-3(\xi/b)^2+2(\xi/b)^3,\quad b=1/8.$$
修正在 $\xi>b$ 处为零，$g_{h,i}$ 使用实际端口节点和分段多项式，因此端口迹逐点恰等于 $g_i$。主场取 $\tau=12s$，比较场取 $8s$，$s=24,48$。其余22列使用精确指数场 $e^{-\sqrt{\beta_i^2-\lambda}\xi}e^{\mathrm i\beta_i y}$ 与其梯度通量。低迹修正与高迹的所有横向分量均在实际积分中保留。

RT3 的72个边/列法向多项式关系已用整数算术检验。共享边系数、横向 Bloch 相位及胞壁通量映射由同一变量定义。通量的法向连续属于构造恒等式。内部基预条件不改变边系数，最终求值回到整数基。无限胞由传递矩阵幂累加；有限幂范数小于1及显式尾界保证 $u\in H^1$、$p\in H(\operatorname{div})$。

残差使用证明 (4.3) 的 $R=\int(|\nabla u-p|^2+|\operatorname{div}p+\lambda\rho u|^2/\rho)$，测试空间为零端口迹的 $\mathcal V_0$，范数为 $e(v,v)=\int(|\nabla v|^2+\rho|v|^2)$。非紧支撑场的 Green 公式及级数误差推导见文末。

## 对下一步的意义

两个交付 JSON 保存未缩放的 $\hat\Lambda,Q,R,Z$、安全方向的 $Q_\pm,R_+,Z_+$、上下界、$K_\pm,a_H,b_H^2,A_H$。系数约定为 $g(y)=\sum_{i=-16}^{16}\hat g_i e^{\mathrm i\beta_i y}$，$y\in[-1/2,1/2]$，保留原物理取向。$\hat\Lambda$ 对全部端口迹给出 C.3 下界，下界在33模外按零嵌入；上界只对保留的33模子空间使用。两侧都达到残差预算。下一步可将两矩阵送入核心计数；最终计数决定当前间隙是否足够。

## 限制

排除舍入，仅处理 $\lambda=\alpha_+$。输入半引线谱间隙采用 h-cert-v1 的结果。D 和最终计数不在本实验范围。特征值符号及残差最优化目前用普通浮点运算；后续区间算术须同时包围几何、积分、矩阵级数和特征值运算。

<details>
<summary>非紧支撑场、全域 Gram 与无穷级数的推导</summary>

取 $\mathcal V_0=H^1_{\beta_0,0}(\Omega)$，$e(v,v)=\int_\Omega(|\nabla v|^2+\rho|v|^2)$，与证明 (4.1) 相同。RT3 的参考基使用整数系数；每个边函数在其本边的法向密度恰为 $(2m+1)P_m(2t-1)$，其他边及内部函数的法向密度为零。72 个边/基函数组合已用整数算术核对。单胞内共享边系数及横向相位由同一全局变量定义，Piola 变换保留法向密度。边反向时法向密度变号、Legendre 多项式再乘 $(-1)^m$，总因子为 $(-1)^{m+1}$；代码的 `G.phase` 正采用该因子。横向上边的系数为下边系数乘 $e^{0.5\mathrm i}$。逐片分部积分的内部面项因此精确相消，得到全域 $H(\operatorname{div})$ 通量。

令 $P$ 为数值传递矩阵，$U$ 为近端口到单胞场的线性映射。首胞场为 $Ug$，第 $n\ge1$ 胞场为 $UPP^{n-1}g$。RT3 内部通量通过最小化 (4.3) 选取；只把它当作试探通量。记首胞远端的全局法向矩映射为 $N_0$，重复胞近、远端映射为 $N_b,F_b$，构造强制
$$N_0=N_bG,\qquad F_b=N_bP.$$
这里 $G$ 把11个低 Fourier 迹映射到节点。法向密度为三次多项式，全部四个矩相同即密度相同。因此通量在所有胞壁严格连续。整数基的内部坐标可以作数值预条件，但最终通量始终以该整数基及原边系数求值。

若有限幂 $\|P^L\|=\eta<1$，则按长度 $L$ 分组的几何级数收敛。对任意单胞 Hermitian Gram $H$，令 $S_L=\sum_{j=0}^{L-1}(P^j)^*HP^j$，则
$$\left\|\sum_{j=0}^\infty(P^j)^*HP^j-S_L\right\|\le\frac{\eta^2}{1-\eta^2}\|S_L\|.$$
同一公式用于 $H=I$，给出积分误差随无穷胞累加的放大界。代码用倍增法产生 $S_L,P^L$；它不以离散谱代替半引线谱证书。

有限单胞内的场、梯度、通量与散度均平方可积。上面的级数使它们在整个半引线平方可积。通量的法向连续又给出 $p\in H(\operatorname{div})$。先对零物理端口迹、纵向紧支撑的测试函数分部积分，再用截断函数逼近任意 $v\in\mathcal V_0$。截断项受 $p,u,v$ 的尾部平方积分控制并趋于零。因此
$$s_\lambda(u,v)=\int(\nabla u-p)\cdot\overline{\nabla v}-\int(\operatorname{div}p+\lambda\rho u)\overline v,$$
物理端口项由 $v|_{port}=0$ 消失。证明 C.1 的残差界可直接使用，无须假定一个人工远端的边界条件。

对 $|i|\le5$，实际场为
$$u_i=u_{h,i}+\chi(\xi)e^{-\tau\xi}(g_i-g_{h,i}),\quad b=1/8,$$
其中 $\chi=1-3(\xi/b)^2+2(\xi/b)^3$ 在 $[0,b]$ 上，其他位置为零；$g_{h,i}$ 是实际 FE 端口迹的分段多项式。因 $\chi(0)=1$，端口迹逐点等于 $g_i$，所有额外 Fourier 分量也相消。$\chi(b)=\chi'(b)=0$ 使校正属于 $H^1$，横向保持相位。$6\le|i|\le16$ 使用 $u_i=e^{-\kappa_i\xi}e^{\mathrm i\beta_i y}$、$p_i=\nabla u_i$，$\kappa_i=\sqrt{\beta_i^2-\lambda}$。

高频解析列在首胞外的能量、残差与组合场平方范数分别由
$$E_H=\max_i\frac{\kappa_i^2+\beta_i^2+17}{2\kappa_i}e^{-2\kappa_i},\quad R_H=\frac{(16\lambda)^2}{17}\max_i\frac{e^{-2\kappa_i}}{2\kappa_i},$$
$$Z_H=(1+16\lambda K_+)^2\max_i\frac{e^{-2\kappa_i}}{2\kappa_i}$$
控制。若重复胞低频能量界为 $E_L$，未计算的 $Q$ 交叉及高频块的范数至多 $\lambda(2\sqrt{E_LE_H}+E_H)$；$R,Z$ 分别用 $2\sqrt{R_LR_H}+R_H$、$2\sqrt{Z_LZ_H}+Z_H$。这些尾界加入矩阵误差。

<summary>解析几何与正权 Gauss 积分余项的推导</summary>

本段为本实验新增界的从零推导；它以 h-cert-proof.md 的 C.1、C.3 及 h-cert-v1 的半引线预解式界为输入。只排除舍入，不以两阶求积之差充当积分余项。

记单元顶点仿射映射为 $v_1+A\xi$。公共单元直接定义为该仿射映射。曲线单元使用
$$F=v_1+A\xi+4\ell_a\ell_b o+r^3\delta(t),\qquad r=\ell_a+\ell_b,\quad t=\ell_b/r,$$
其中 $o=c(t_{mid})-(v_a+v_b)/2$，$\delta$ 为真弧减去其二次插值。Duffy 坐标中的 $r,t$ 各在参数2、映到 $[0,1]$ 的 Bernstein 椭圆内。于是 $|r|,|t|,|1-t|\le1.125$，$|t-1/2|\le0.625$。三叶形的 Fourier 频率是 $1,2,4$，每个坐标的振幅上界依次为 $R,Ra/2,Ra/2$。

写 $T_j(z)=\sum_{k\ge j}z^k/k!$。对每个频率 $\nu$，令 $z=\nu\Delta\theta$，则
$$|\delta|_\infty\le\sum_\nu a_\nu\{T_3(0.625z)+2.8125T_3(0.5z)\},$$
$$|\delta'|_\infty\le\sum_\nu a_\nu\{zT_2(0.625z)+7T_3(0.5z)\}.$$
这是先减去中点 Taylor 二次式，再对剩余项作三点插值所得的界。 两个端点 Lagrange 系数分别是 $-2(1-t)(t-1/2)$ 和 $2t(t-1/2)$，模之和至多2.8125；其导数模之和至多7，中点余项为零。代码把正项求到40阶；后续项比不超过 $z/42$，故用首个未计项除以 $1-z/42$ 包围。实际所有 $z$ 都满足该分母为正。

利用
$$J-A=4o(\ell_a\,d\ell_b+\ell_b\,d\ell_a)+r^2\{3\delta\,dr+\delta'(d\ell_b-t\,dr)\},$$
代码分别计算 $\eta=\|A^{-1}(J-A)\|_\infty$ 与 $\eta_{phys}=\|(J-A)A^{-1}\|_\infty$ 的上界。两者均小于1。因特征值模不超过矩阵无穷范数，整个复椭圆上有
$$|\det J|\ge\det A(1-\eta)^2,\quad |\det J|\le\det A(1+\eta)^2,\quad \|J^{-1}\|_\infty\le\|A^{-1}\|_\infty/(1-\eta).$$
实单胞上的分片位移连续，外胞壁位移为零，物理坐标导数范数小于1；延拓为零后仍是全局 Lipschitz 位移。对任意目标点，迭代 $x_{n+1}=y-d(x_n)$ 的差按几何级数下降，给出唯一原像。因此分片映射全局一一对应，材料标签与真弧一致。这一判断覆盖整个单元，不只覆盖求积点。

首胞端口修正按 $\xi=1/8$ 和实际端口多项式的各个横向分段裁剪仿射三角形。每个裁剪子三角形独立积分；不丢弃任何正面积片。曲线单元到修正带的距离由复位移上界核查为正。每个积分片上均只有一个解析表达式。公共重复胞上的 $Q,R,Z,E$ 密度是次数至多8的多项式；Duffy 后各变量次数至多9，16阶 Gauss 精确。

其余积分片上用系数 Frobenius 范数给出整块矩阵的算子范数界。设 $\Lambda=2$（裁剪后的仿射片取4），$n_b$ 为场基函数数目，$U_e$ 为场系数，$c_e$ 为整数 RT 基的单项式系数，则
$$|u|\le\sqrt{n_b}(p\Lambda+p)^p\|U_e\|_F,\quad |\partial_{ref}u|\le\sqrt{n_b}\,2p^2(p\Lambda+p)^{p-1}\|U_e\|_F,$$
$$|p_{ref}|_\infty\le\sqrt{24}\Lambda^4\|c_e\|_F,\quad |\operatorname{div}_{ref}p|\le5\sqrt{24}\Lambda^3\|c_e\|_F.$$
用上述 $J^{-1},J,\det J$ 界完成梯度和 Piola 变换。解析列的指数由 $\Re\xi$ 下界和 $|\Im y|$ 上界控制。Duffy 复重心坐标的负实部总量至多0.6875、虚部绝对值总量至多2.0625，所以
$$\Re\xi\ge\min_v\xi_v-0.6875\operatorname{span}_v\xi-d_{geom},\qquad |\Im y|\le1.03125\operatorname{span}_v y+d_{geom}.$$
对裁剪片，$\xi/b$ 的复值是顶点处 $[0,1]$ 数据的仿射插值；其模不超过 $\max_j(|\ell_j|,|1-\ell_j|)<3$。因此端口修正的三次截断函数及其物理导数分别用82和576控制；加上衰减指数后，导数界再加 $82\tau$。实际端口多项式系数也按其 Frobenius 范数包围。

设由此得到 $u,\nabla u,p,\operatorname{div}p$ 的上界分别为 $u_b,g_b,p_b,d_b$，每个梯度/通量分量分别受 $g_b,p_b$ 控制；$j_b$ 是含 Duffy 和子片面积因子的 Jacobian 上界。代码取
$$M_Q=j_b(2g_b^2+\lambda\rho u_b^2),\quad M_R=j_b\{2(g_b+p_b)^2+(d_b+\lambda\rho u_b)^2/\rho\},$$
$$M_Z=j_b\{u_b+K_+(d_b+\lambda\rho u_b)\}^2,\quad M_E=j_b(2g_b^2+\rho u_b^2).$$
这些是矩阵算子范数界，不是逐项界；无需再乘矩阵阶数。中心值始终先形成残差及 $z$ 再形成 Gram。复延拓中，共轭因子按 $\overline{f(\bar z)}$ 延拓，仍解析，并受同一对称椭圆界控制。

最后证明求积误差常数：参数2椭圆内有界解析函数的 Chebyshev 系数可由圆周 Fourier 积分得到，系数范数至多 $2M2^{-j}$。截断到次数 $2q-1$ 的尾范数不超过 $4M2^{-2q}$。映到 $[0,1]$ 后，积分及正权 Gauss 规则的范数均为1，单变量误差至多 $8M2^{-2q}$。对张量规则逐变量作差得到至多 $16M2^{-2q}$；代码采用更宽的
$$\varepsilon_{elem}=32M2^{-2q}.$$
按此界逐元选阶并累加，得到 JSON 中的积分误差；随后另加无穷级数误差和高频尾交叉界。该余项不包含浮点舍入。
