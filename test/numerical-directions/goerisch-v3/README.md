# Goerisch 第 3 版：直接场升阶与等精度成本比较

D 指 direct tapered trial（直接截断试探场），R 指 reconstructed trial（重构试探场），FEM 指 finite element method（有限元法），DtN 指 Dirichlet-to-Neumann，RT 指 Raviart–Thomas，RSS 指 resident set size（驻留内存）。JSON 指 JavaScript Object Notation，CSV 指 comma-separated values。P2／P3 指二次／三次有限元场，`goerisch-v3` 是 Goerisch 实验第 3 版。

**本轮仅加密 D，未重跑 R。P3/RT2 得到原始宽度 $9.13357\times10^{-9}$，约为目标的 $1/20.65$；因一致性检查触发预设停止规则，尚未完成全部核查，等精度成本仍待确定。** 全部结果是普通浮点，沿用原谱假设与尚未认证的谱隙端点。

## 目标与控制变量

固定目标为已有 v2 R/run-003 的宽度 $W_{\rm target}=1.8863227554484077\times10^{-7}$，单位为 $\mu$。测量直接路线达到该宽度所需的场生成、Goerisch 正式计算、额外核查时间和内存。候选 R 只读取既有标量作比较，不生成源矩、不重新计算或优化 R。

原 native 场为 P2，背景每胞元 48 等分、解析界面 320 段；左／中／右模板有 6410／6330／6392 个三角形，自由度为 12916／12756／12880。本轮保持同一曲边几何、材料、相位、截断、位移及谱隙端点，将场次数升到 P3。先复现 P2/RT3，再以 P2/RT2 为同通量空间的粗层对照，最后测试 P3/RT2。没有运行 P4 或通量扫描。

固定物理和积分设置与 [v2](../goerisch-v2/README.md) 一致：$\beta=0.5$、$\gamma=1$，谱隙端点 $1.3174^2,2.1875^2$，通量区域 $[-13.5,13.5]\times[-0.5,0.5]$、原余弦截断、材料 1／4／17、解析界面拟合几何及 Piola 映射；主／核查积分阶 16／24，native 材料修正阶 10／16，两个 MATLAB 计算线程。

## 方法与预设检查

`direct_native.m` 从 I10.2 复制必要的网格、空间、真实材料质量矩阵、DtN 和区间求根函数。在同一 g48 网格上建立高阶场，从原频率 1.558438079544167 开始求根。BIE 参考只用于结果包含检查，不参与求根。组装、lead 计算、所有求根迭代和场恢复均计入生成成本；不产生重构场或源矩。

`direct_pipeline.m` 沿用 v2 的 D 路径。高阶节点值先转成参考单项式系数，按实际场次数计算值与梯度，经原二次几何 Jacobian 转换，再施加余弦截断及其导数。独立使用 I10.2 的重心 Lagrange 基，在每模板 31 个单元、所有重复胞元比较值与物理梯度，预设相对容差 $10^{-10}$，避免把 P3 系数送入 P2 求值器。

启动前规定：P2 基准 $q$ 相对差不超过 $10^{-12}$，宽度相对差不超过 0.005，$J$ 缩放差不超过 0.01；两种宽度公式绝对差不超过 $10^{-13}$，符号、分母及 BIE 数值包含成立。面积相对误差低于 $10^{-12}$，胞元／相位迹低于 $10^{-10}$，外法向通量矩为零。沿用 v2 求解残差与通量迹门槛。

每组同一场／通量用 24 阶积分核查，不重新求解；要求 $q|J_{24}-J_{16}|/(qJ_{16}-1)<0.01$，Gram／逐点同样使用此缩放及门槛。Rayleigh 商相对变化低于 $10^{-12}$，且变化小于区间宽度的 1%。经理提示词规定任何数值检查失败即停止，保留输出。

## 为什么在约 51 秒停止

| 层级 | $J_{\rm Gram}-J$ | $qJ-1$ | 缩放差 | 1% 门槛 |
|---|---:|---:|---:|---|
| P2/RT3 | $2.15605\times10^{-12}$ | $1.63969\times10^{-7}$ | 0.004508% | 通过 |
| P2/RT2 | $5.34883\times10^{-12}$ | $1.64164\times10^{-7}$ | 0.011172% | 通过 |
| P3/RT2 | $5.36976\times10^{-12}$ | $4.16134\times10^{-10}$ | 4.424404% | 未通过 |

P3 的两种 $J$ 算法绝对差仍约 $5.37\times10^{-12}$，但区间依赖的小量 $qJ-1$ 明显下降，因而缩放差升到 4.42%。**这不是 $J$ 本身的相对误差为 4.42%，也不是时间或内存超限。** 差异来源尚未定位，不能直接归因于舍入，也不能据此断言 P3 无法达到目标或区间必定错误。

程序按经理提示词的“检查失败立即停止”规则，跳过了之后的高阶积分和归一化核查。该停止规则对本次等精度成本目标过于机械：原始宽度比目标小约 20 倍，合理的后续工作是检查同一配置的差异是否影响目标判断。历史 1% 检查结果保持原样，不事后放宽门槛把这次运行标为通过。

## 检查结果与资源

1. **基准通过。** P2/RT3 的 $q,J,W$ 与 v2 完全相同；P2/RT2 为同通量空间的粗层参照。
2. **标量代数通过。** 三行原始结果的端点、两种宽度、正分母、$\kappa$ 符号、正 $qJ-1$ 和 BIE 数值包含通过独立重算，公式差小于 $1.5\times10^{-15}$。这不等于 P3 全部检查通过。
3. **积分检查未全部完成。** 两 P2 行的 16／24 阶缩放差为 $2.32\times10^{-9}$、$9.28\times10^{-9}$，商相对变化 $1.30\times10^{-16}$；均通过。P3 Gram 缩放差 0.04424404 超过 0.01，高阶积分及归一化核查未执行。
4. **已保存的几何、求值与通量检查通过。** P3 网格节点与原网格完全相同，共享边位置及 P3 迹差为零；独立 Lagrange 对照的值差不超过 $4.91\times10^{-16}$，梯度差不超过 $6.05\times10^{-14}$。外法向矩为零，法向迹误差 $1.46\times10^{-14}$，全局残差 $1.06\times10^{-15}$，单元残差低于 $1.72\times10^{-12}$。P3 主面积及原生胞元／相位断言已执行，但部分具体标量未保存，档案不完整。
5. **计时部分完成。** P2 对账通过，P3 生成分项完整；P3 正式总计与额外核查缺失，原因见上。
6. **资源符合预算。** 两次进程共 133.399371 秒，最大 RSS 2.207642 GiB。停止时仍有充裕预算。新目录小于 0.5 MB，worktree 约 188.43 MB；未跟随外部符号链接。

启动前 P2 完整预计 100–150 秒、低于 2.7 GiB；完成对照后，P3 预计总计低于 300 秒、低于 2.8 GiB。两个进程共享 30／40 分钟和 3 GiB 上限。后者启动时已用 82.641 秒，监测器接收剩余预算，没有重置。
