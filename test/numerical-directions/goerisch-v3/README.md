## 平方积分、Gram 诊断与检查

代码中的 $v,p$ 未预先归一化，令 $M=\int\rho|v|^2$。实际计算为

$$\frac{q}{M}\int_D\left(\left|p-\frac{\nabla v}{q}\right|^2+\frac{|\operatorname{div}p+\rho(1-1/q)v|^2}{\rho}\right).$$

场系数已经包含准周期相位；使用物理梯度与 Piola 映射后的物理散度，符号与 $\operatorname{div}p+\rho v$ 一致。D 的余弦截断在盒外为零，所以尾项为零。积分点与 $J$ 相同，梯度逐批求值。平方值还用稳定公式 $E(t)=q-1+qt\varepsilon/(q-t-t\varepsilon)$ 算端点，其中 $\varepsilon$ 为平方积分所得小量。

run-002 的停止原因是当时把 Gram／逐点差异设成了有效性门槛。该比较反映求解所用二次型与最终泛函的一致性。容许通量上的逐点泛函才进入区间；求解不精确会增加泛函值，因此本次移除 Gram 门槛，保留诊断数值及原失败档案。

## 方法与预设检查

`direct_native.m` 从 I10.2 复制必要的网格、空间、真实材料质量矩阵、DtN 和区间求根函数。在同一 g48 网格上建立高阶场，从原频率 1.558438079544167 开始求根。BIE 参考只用于结果包含检查，不参与求根。组装、lead 计算、所有求根迭代和场恢复均计入生成成本；不产生重构场或源矩。

`direct_pipeline.m` 沿用 v2 的 D 路径。高阶节点值先转成参考单项式系数，按实际场次数计算值与梯度，经原二次几何 Jacobian 转换，再施加余弦截断及其导数。独立使用 I10.2 的重心 Lagrange 基，在每模板 31 个单元、所有重复胞元比较值与物理梯度，预设相对容差 $10^{-10}$，避免把 P3 系数送入 P2 求值器。

启动前规定：P2 基准 $q$ 相对差不超过 $10^{-12}$，宽度相对差不超过 0.005，$J$ 缩放差不超过 0.01；两种宽度公式绝对差不超过 $10^{-13}$，符号、分母及 BIE 数值包含成立。面积相对误差低于 $10^{-12}$，胞元／相位迹低于 $10^{-10}$，外法向通量矩为零。沿用 v2 求解残差与通量迹门槛。

每组同一场／通量用 24 阶积分核查，不重新求解；要求 $q|J_{24}-J_{16}|/(qJ_{16}-1)<0.01$。Rayleigh 商相对变化低于 $10^{-12}$，且变化小于区间宽度的 1%。历史 run-002 曾错误地对 Gram 也施加 1% 停止门槛；收尾代码已将它改为纯诊断。
