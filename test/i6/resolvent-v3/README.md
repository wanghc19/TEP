## 精确对象与认证范围

$\widehat k$ 是冻结 MAT 中的精确 binary64 值，
$\mu=\widehat k^2=4258097860352843097504719264809/1267650600228229401496703205376$。
旧 `mu_h` 只作诊断；它与这个实平方相差约 $-1.94\times10^{-16}$。
$\beta=1/2,d=L=1,\rho_e=1,\rho_{\mathrm{disk}}=17$。
圆半径与 collar 宽是存储的精确 dyadic，分别打印为 0.2 和 0.04；不是任意重解释的有理数。

冻结 double 与整数数据通过无损二进传输；整数转换保存原类型并检验往返完全一致。
有限密度的数学 DFT、全 $P_\pm,G_\pm,c_\pm$、特殊函数、强相消、Gram 质量与 F14
全部用球算术。原始场由完整精确准周期核定义，逐片 PDE 和准周期缺陷为零；
评价核的截断误差进入边界界，不重新定义 raw 场，也不引入 lift。

认证涵盖全谱距离 $R_{\mathrm{spec}}$，它不是 residual 范数。
本轮不证明带隙、离散特征值存在性、唯一性或编号，也不认证此前 candidate 搜索。
认证以所用 Arb/FLINT 基础库的包含性合同及正常硬件执行为基础，不是整个软件栈的形式化证明。
