## 结果（$\mu$ 单位，$\mu=k^2$）

所有半径都按设计第 5 节计算：

- $B_{g,4}=|\widetilde\nu_{g,4}-\widetilde\nu_{g,3}|+3\times10^{-10}$
- $R_{g,0}=|\mu_0-\widetilde\nu_{g,4}|+B_{g,4}$
- $R_{g,N}=|\mu_{g,N}-\widetilde\nu_{g,4}|+B_{g,4}$
- 可选的 $B_{g,p}=|\widetilde\nu_{g,p}-\widetilde\nu_{g,4}|+B_{g,4}$（$p=2,3$）

$k$ 半径使用精确区间 $[\sqrt{m-R},\sqrt{m+R}]$ 的最大单侧半径 $R/(\sqrt m+\sqrt{m-R})$。三组均满足 $R<m$，没有区间被截断。汇总脚本重算的 $B_4$、$R_0$、$R_N$ 与 MATLAB 估计逐位相同。
