## D2 实施内容（只改本目录）

1. **薄带 owner（§3.2）**
   - 每个带点在接受的逆映射中按字典序 $(-b_K,\ r_K/h_K,\ \text{全局单元号})$ 唯一选择 owner，其中 $b_K$ 为参考重心坐标最小值。
   - 阶段 A 查界面边的两个单元。若最佳 $b_K<0$，补查一次：先 B（顶点邻元），再 C（Bernstein AABB，排除已试单元）。补查后仍为负的点计为 `tolerance_owner`。
   - 真失败只有两类：无接受逆映射（`POINT_LOCATION_FAILED: NO_ACCEPTED_INVERSE`），或错胞。
   - 双解全局值差只作诊断：每胞记录 `dual`、`dual_defect_max`，最多保留 20 个最大差样本（含两侧单元、$b_K$、$r_K/h_K$、权重）。D1 的拒绝门与 `dual_value_tol` 已删除。
2. **真共享边迹检查（新增阶段）**
   - 对每个模板内两单元共享的每条 $P_2$ 边，在从较小全局顶点量起的参数 $0,1/4,1/2,3/4,1$ 处比较两侧：$P_2$ 几何，以及 $P_2/P_3/P_4$ 全局基行。
   - 容差 `edge_tol = 1e-10`。不通过时 `SHARED_EDGE_TRACE_FAILED`。
3. **根资格与诊断分离（§5.1）**
   - Stein 质量记录为 `mass_status`（`STEIN_RESOLVED` / `STEIN_TAIL_UNRESOLVED` / `MASS_NONPOSITIVE` / `MASS_NONFINITE`），不进入恢复门或根资格。
   - 预测与导数检查只作诊断。
4. **数值零与括区**
   - 不再构造零宽括区。括区须严格异号。
   - 起点为数值零时，由两侧异号点构成括区。
   - Brent 去掉 `fb==0` 捷径。命中零时向另一端微移，最多 2 次。
   - 根有严格括区且残差 $\le10^{-9}$，但未达分辨目标时，状态为 `ROOT_CANDIDATE_UNRESOLVED`：仍交数值 candidate，并把该层评价降为 `EVALUATION_UNRESOLVED`。
5. **估计依赖（`LOCAL_estimate`）**
   - $B_4=d_{34}+\epsilon_3+2\epsilon_4$ 与 $R_0=|\mu_0-\widetilde\nu_4|+B_4$ 只依赖 $P_3/P_4$ 根。
   - $R_N=|\mu_N-\widetilde\nu_4|+B_4$ 另需有限 $\mu_N$。
   - $P_2$ 只进入 $d_{23}$、$q_{\rm obs}$ 和符号翻转判断。
   - 最终状态由同模 `pass_34` 与 `evaluation_resolved_P34` 决定；$P_2$ 相关项只进备注。
6. **启动器**：残留进程改为退出时与等待 15 s 后各记录一次（`{at_exit, after_wait}`），避免把正在退出的子进程误记为残留。
