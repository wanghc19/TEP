# Cloud theory guidance

Read and follow the root `AGENTS.md` and `research/AGENTS.md` before work.

- At task start, confirm the designated baseline branch or commit and that the
  working branch includes its current shared rules. If no baseline is specified,
  clarify it before substantive research; do not choose between branches silently.
- Write theory documents, progress records, and handoff notes only in
  `research/cloud/`; put temporary derivations in `research/cloud/tmp/`.
  Keep status and issue records here even when studying an existing project.
- Other directories are read-only. Do not modify code, shared rules, or other
  research records; describe needed cross-directory changes in a handoff note
  for local integration. This directory is for theoretical work, not experiments.
- Follow the root push-authorization and synchronization rules. Review outgoing
  task changes for scope; resolve conflicts outside this directory with the user.
