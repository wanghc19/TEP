# Fredholm framework

## What index zero would require

An index statement needs one bounded operator between fixed spaces. A relation block written as “belong to this subspace” is not automatically square. The first task is to choose either:

1. stable Riesz coordinates and equality in the full trace space;
2. a quotient by the outgoing subspace;
3. a multitrace/Calderón projector equation.

Only after domain and codomain dimensions/indices are balanced can one seek

\[
\mathcal A=\mathcal A_0+\mathcal K,
\qquad \mathcal A_0^{-1}\in\mathcal L(\mathcal Y,\mathcal X),
\qquad \mathcal K\ \text{compact}.
\]

## Candidate principal operator

Normalize the stable trace synthesis by its Riesz isomorphism so its principal coordinate block is an identity. Combine this with the diagonal Calderón/Müller principal block on the interface. Candidate compact terms are smooth QP-minus-free-space remainders, traces between separated curves, and finite homogeneous couplings. Each candidate must be proved compact; “off diagonal” is not enough.

## Separation from spurious-free claims

Fredholm index zero gives finite-dimensional kernel/cokernel and index balance. It does not identify the kernel with a physical field and does not control inverse norms. K1/L13 perform kernel identification; Hiptmair--Moiola--Spence explain why quasi-resonant conditioning remains a separate issue.

## Failure route

If no natural square `\mathcal A_0` exists, publish no forced continuous index theorem. Downgrade to closed range/finite kernel, a quotient-space statement, or a finite-Rayleigh square theorem. This is the planned Package B switch.
