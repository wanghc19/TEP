# R1：例一的复现与校验包

## 包与规范数据

`release/bie-enclosure-sisc/` 提供两个入口：`scripts/reproduce.py` 从空目录做搜索、密度重建、B 拟合及全部可靠计算；`scripts/verify.py` 只用规范数据和 Python 重算五组缺陷、尾项、质量下界、迹常数、装配和公共谱隙。只支持例一。`src/matlab/` 包含实际加载的共享函数和搜索代码；`src/python/` 包含可靠计算与核查。`data/ex1/` 保存本包冷启动产生的场，`data/README.md` 说明每个数组的形状、列主序、坐标、密度符号和论文公式；`reference/` 保存中间界、表格和容差，`tests/` 提供 smoke test 与故意失败对照。

规范系数用 JSON 中的 IEEE-754 binary64 十六进制字表示，实虚部分开。几何以这些 binary64 参数为目标，导出后的傅里叶系数和 B 系数定义实际连续场。参数不依赖旧实验结果；重新拟合可产生不同的场，参考结果对应规范数据。包约 14.93 MB，其中 `data/ex1/` 为 13.54 MB；没有 MATLAB 格式的规范数据。

FMM2D 不随包分发；复现显式接收其外部 MATLAB 安装路径，记录已测版本及 Apache-2.0 许可。verify 不使用 MATLAB 或 FMM2D。项目自身许可证保留 `LICENSE` 的 TODO，由作者决定。

## 核查与成本

I1 在中心与右材料各取一个独立实点，分别形成外侧、内侧完整迹，包含半密度跳项、近邻像、拟合的 480 个点源及入射项。两频率共有的 Laplace 奇异层在差中精确抵消；其单侧显示值为辅助求积，差值的余项由两个频率相关积分分别包围。几何和 Kress 基础公式沿用生产代码，跳值计算路线独立于生产插值模型。

| I1 核查 | 中心 | 右材料 |
|---|---:|---:|
| 直接跳值与生产模型的加权差 | 1.94756e-32 | 2.08178e-37 |
| 生产模型误差上界 | 2.40328e-18 | 4.84181e-22 |
| 直接计算误差上界 | 1.94598e-55 | 9.91608e-38 |
| 拟合 B 点源的迹范数 | 0.246543 | 0.333408 |

仓库外临时副本的 verify 通过：独立覆盖/分组求和及 Gauss 积分、N+10 尾检验、两配置迹常数、两精度与有理数装配、472 个带符号、4 个 LDL* 惯性检验、I1、smoke test。469 条 Python 打开文件记录未出现仓库内读取；审计范围为 CPython 打开/导入，不是 C 库内部系统调用跟踪。故意失败对照给出第二负方向上界约 -12.2998，按预期被拒绝。

## 复现与后续

包 README 给出三个带显式路径的命令。典型校验命令为 `PYTHON -I PKG/scripts/verify.py --data PKG/data/ex1 --reference PKG/reference --output EMPTY_DIR --workers 8`；外部副本校验另传 `--forbid-root ORIGINAL_REPOSITORY`。

R2 需要把第二例及近带边例的参数、空中心/异周期/旋转几何、全相位带检验和一般 p 尾分支接入这些公开入口，并分别生成规范数据与参考结果。R3 添加 FEM 对照的独立入口和同等起点成本；本包没有运行这两部分。
