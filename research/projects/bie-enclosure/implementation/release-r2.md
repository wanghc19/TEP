# R2：四个空中心点的复现与校验包

`release/bie-enclosure-sisc/` 已支持 ex1、ex2-L1、ex2-L1.6、ex2-L1.9、ex2-L2。四个新点各完成一次空目录冷启动，再以本次生成的规范数据独立运行纯 Python verify。L1.6 本次为一个完整驱动，未拼接旧运行。包约 74.868 MB；例一数据 13.540 MB。开放 JSON 字典说明空中心零密度／零反射／自由传播、不等周期、旋转、全相位 band 输入和一般 p 尾界。

- 四个新点 verify 的全部打印科学值与各自冷启动逐字相同；独立残差覆盖与积分审计、两精度／精确有理装配、每点 944 个全相位符号、8 个 LDL* 检查及拒绝错误阈值的对照均通过。例一的 472 个符号、4 个 LDL* 及双侧迹检查通过。

## 复现与 R3

按包 README 设置软件路径，运行 `scripts/reproduce.py --example NAME --output RUN --python PYTHON --matlab MATLAB --fmm-root FMM_ROOT`，随后运行 `scripts/verify.py --example NAME --data DATA --reference REF --output VERIFY_RUN`；输出目录须为空。R3 需新增 FEM 的独立入口、规范数据、核查程序及成本对照。本次未运行 FEM＋Goerisch 对照链；发布许可证仍由作者决定。
