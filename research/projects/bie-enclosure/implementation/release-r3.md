## 验证与数据

规范数据采用 NPZ/JSON，含实际场与通量系数，无场值缓存。数组往返同时核对 MATLAB 数值类型、形状和数值位；原生场 13.36 MB、通量 61.45 MB，连同 H 数据约 76.29 MB，包约 151.72 MB。

run-006 在单三角形批次触发行/列隐式扩展，40.15 s 后停止；run-007 以实际批次确认 256×1 权重除以 1×256 材料值的原因，修复只明确重复方向。run-010 在读取规范参数时停止（19.74 s）：MAT v7 的压缩整数存储被误当作原 MATLAB 类型；run-011 修复为保存原数值类型，同时保留复数虚部，完整核对通过。两次均为实现错误，未更改任何符号门槛、积分点或余项，失败记录保留。

run-012 重算 E/M/S 和两组十进制端点，全部精确一致，621.36 s、1.498 GiB；run-013 重算 472 个带隙符号、表面/DtN 判据与核心计数和裕量，全部一致，19.67 s、0.987 GiB。错误相位、无效带隙输入均被拒绝。共享通量矩差 8.94e-19，胞间差与外侧法向矩为零。最终路径扫描和 BIE ex1 smoke 通过；278 个原包文件中仅总 README 改动，BIE 代码、数据、参考数值及共享脚本不变。科学输入读取均在包或当前验证输出内，55 个 MATLAB 文件均有实际加载记录。verify 重算 E/M/S、A 和 D；B/C 读取规范积分矩阵及解析余项，再重算有限判据，不重新生成响应场。截断误差按原方法给界，有限舍入仍只估计。BIE 与 FEM 的一个几何 Fourier 系数相差 2^-56，区间嵌套只是数值交叉核对。
