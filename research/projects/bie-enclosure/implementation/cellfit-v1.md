# 胞元核逐场拟合与可靠先导

cellfit 为 cell kernel field fit（胞元核逐场拟合）。**选择 B 进入整曲线阶段。** 五组浮点预算、中央两面板紧门槛及在线时间均通过。但完整引线代数比旧成本模型贵；本次更新的残差评价预测为 B 串行约 81 分钟、八进程约 47 分钟。

## 输入与拟合

输入为指定 `fixed-input.json` 的逐字节相同副本；密度、传播矩阵、材料内场不变。A 保存本次重拟合的全部480系数，B 在本实验重新拟合195右端；拟合输出按确切 binary64 定义，随后用 Arb 球运算。代理位于物理 $x=\pm1.45$ 或 $y=\pm1.35$。实际域检查通过，移动／固定代理到闭胞元的净空分别可取 0.589998 / 0.849999。

## 可靠目标

## 经理核对（2026-11-05）

- 用 cellker-v1 隐含的 $C_g$ 由五组表重算：$Q_A=3.528353\times10^{-12}$、$Q_B=3.521214\times10^{-12}$，比值 0.99798；宽度 $2.77356/2.76795\times10^{-11}$。中央两面板 $e_I$ 按自作用、光滑、局部尾三项相加复现 A $2.3877/3.2969$、B $2.4033/3.3125\times10^{-18}$。均与报告一致。
- 成本：`output/cost-projection.json` 中边界近像区域准备 2255.6 秒（每个引线边界段约 23 秒）占 B 串行总量的 46%，引线材料在线 1638 秒占 34%；中心部分只占约 8%。这两项都来自引线的 194 列状态映射。
- 八进程 47.0 分钟把全部区域准备按串行计。各边界段的区域准备互相独立，若同样分给 8 个进程（只保留源准备、拟合和质量检查为串行），按同一效率外推为 B 约 15.5 分钟、A 约 22.5 分钟；这只是另一种外推，未运行。
- B 的系数保存在 `output/`（git 忽略）；可由同一入口在约 3 秒内重新拟合，但下一阶段应直接读取本次保存的文件并记录其路径，以免换成另一个场。
