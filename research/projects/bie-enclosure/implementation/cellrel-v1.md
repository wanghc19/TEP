# 胞元核 B 的中心整曲线与引线状态列

cellrel 为 cell kernel reliable evaluation（胞元核可靠评价）。中心整曲线已通过：$\varepsilon_{center}\le1.261591\times10^{-12}$，相对 B 浮点值的比值为 1.00041455。实际状态列保留了引线段贡献，并减少了列相关计算。

## 输入和方法

使用 cellfit-v1 的确切输入与 B 系数逐字节相同副本，不重新拟合。两份输入显式传入，保存在 `cellrel-v1/output/input/`。源矩、普通近像展开、固定代理展开和自作用源网格只在父进程准备一次，然后以 fork 的只读共享页传给动态队列；每个工作进程一个 FLINT 线程。源矩球和展开系数球完整保留。

## 引线状态列

先用完整194列复现，再在形成源矩、自作用与普通展开前乘入 $w_j=GP^jc$；B代理系数乘入 $P^jc$。每列独立支付解析余项和球半径，有限和按CK18计算。局部 Fourier 系数缓存同时用于两条路线，故完整列的局部项从旧记录4.13秒降至本次.537秒不计作列压缩收益。未做可选低秩压缩。

无限尾不依赖完整残差映射：CK20点源行范数加普通层与Kress解析包络，给出右引线整组算子上界 $B_{mat}\le5.784415\times10^6$、$B_{wall}\le2.512755\times10^6$、$B_{seam}\le3.623992\times10^6$。对64个材料参数域执行了自作用包络检查；$p=1$、$r=\|P\|_F\le.386733374894634$。以现有扫描 $C_g$ 选深度：$N=58$ 的加权尾为 $1.12514\times10^{-17}$，$N=59$ 为 $4.31980\times10^{-18}$，故59是这套包络下的最小值。扫描 $C_g$ 仍是浮点输入；各段未加权尾与贡献上界由球运算计算。

## 外推与结论

以中心单进程面板1.703秒和实测八进程队列效率.78076外推。中心192面板、两侧材料128面板、中心边界48段、引线边界96段；右侧59状态的价格用于两侧，内墙按每面区域计价。源几何共享、近像准备、尾包络、历史B拟合／质量／控制点代价分别列入 `output/cost-projection.json`。

| 八进程，边界区域准备串行 | 17.98分钟 |
| 八进程，边界区域准备也分发 | 7.16分钟 |

中心整组83.200秒是实测；上表其他组与并行政策是预测，均低于FEM的67分钟参考墙钟。尚未测左引线所需深度、其他目标域及完整引线并行内存；不包含候选搜索、可靠 $C_g$ 或带隙证书，因而不构成完整保证流程的成本比较。全阶段含两次停止记录共监控645.456秒，最高进程树RSS .513 GiB。

结论：继续B路线和实际状态列。中心整曲线的可靠上界已完成；右侧材料、接合墙、内墙试点支持用实际状态代替194列残差映射，尾部由独立解析包络支付。复现命令和逐段账本在实验README及 `output/curve-panels.csv`、`output/results.json`。
