# Phase 2 source investigation

本目录保存 Eigenvalue a posteriori error 专题的 Phase 2 检索、原文核验、来源分级和
阶段末的有限综合。它不生成论文草稿，也不把候选 estimator 升格为已证明结论。

- `search-plan.md`：预先定义的检索问题、关键词和纳入/排除标准。
- `search-log.md`：逐次查询、命中、筛选和原文获取记录。
- `r-dtn-def.md`：DtN 定义与构造的逐来源核验卡，未核验内容必须显式标记。
- `r-bie-dtn.md`：BIE--DtN 接口的逐来源核验卡。
- `r-nep-error.md`：simple nonlinear eigenvalue perturbation、two-level correction 和
  estimator 强度分级的证据审查。
- `r-sources.md`：来源存在性、元数据和质量核验。
- `r-da2.md`：Phase 2 进入分析阶段前的 devil's-advocate checkpoint。
- `synthesis-dtn.md`：在证据卡完成后的 DtN 定义澄清、路线区分和 Phase 3 入口判断。

跨来源综合必须明确区分“来源直接支持”“由多来源推得”和“尚待验证”。
