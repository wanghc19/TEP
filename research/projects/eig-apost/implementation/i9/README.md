固定 $\beta=0.5$。负侧/正侧分别使用 $a=0.12/0.20$ 的解析三瓣径向曲线；两者朝同一全局方向，不镜像，各自面积 $0.04\pi$。中心保持等面积五瓣星形。几何方向、闭合、解析一二阶导数、非零速度与边界间距通过检查。负侧和正侧独立构造散射矩阵，分别使用逆向和正向衰减子空间。

两侧在初始 $[1.45,2.25]$ 的 33 个探索点均为数值 `GAP`。本次识别的是**两端被窗口截断的采样支持带隙段**，没有定位真实带边。加入内缩缓冲后，实际共同搜索区间为 `[1.4509999999999998,2.249]`。三个代表点的 128/256 lead 检查均保持两侧 GAP；相对散射矩阵差约 $2.66\times10^{-16}$ 至 $1.94\times10^{-15}$，不据此声称全窗口收敛。
