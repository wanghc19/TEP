## 3. 显式通量与公式—变量口径

参考生成基为 $[\mathbb P_2]^2$ 的12个分量单项式，加
$\boldsymbol\xi\xi_1^2,\boldsymbol\xi\xi_1\xi_2,\boldsymbol\xi\xi_2^2$。
参考边逆时针依次为 $(0,0)\to(1,0)\to(0,1)\to(0,0)$，
九个边矩采用 $L_0=1,L_1=2t-1,L_2=6t^2-6t+1$，六个内部矩采用每分量的 $1,\xi_1,\xi_2$。
15×15矩阵只生成一次；用多项式矩核对单值性和对偶基，不能依赖一个未经检查的预填系数表。

对同一原生梯度 $q_K=\nabla u|_K$，先取
$\widehat q_K=\det(J_K)J_K^{-1}J_K^{-T}\widehat\nabla\widehat u_K$，求15矩得局部 $p_K^0$。
物理通量及散度严格采用

$$
p\circ F_K=\frac{J_K\widehat p}{\det J_K},\qquad
(\operatorname{div}p)\circ F_K=\frac{\widehat{\operatorname{div}}\widehat p}{\det J_K}.
$$

内部边统一参数方向、法向后将两侧矩平均。参数反向的第 $m$ 个矩乘 $(-1)^m$；
外法向变号另行记录，不混为一个方向号。上下边同取向右参数和 $e_y$ 法向，
上边先乘 $e^{-\mathrm{i}\beta d}$ 拉回下边后平均，再乘 $e^{\mathrm{i}\beta d}$ 恢复。
人工端矩和六个内部矩不变。人工端通量不强制为零，直接按实际曲边参数速度积分。
最终每条内部边只处理一次；真实材料界面穿过单元时不另造梯度跳跃。

| 理论量 | 数值口径 |
|---|---|
| $U^2$ | 全有限条带的 $\int\rho|u|^2$，零延拓后的全场质量；不是BIE背景圆盘质量 |
| 梯度差平方 | $\int|\nabla u-p|^2$，先相减再取模平方 |
| 加权体缺陷平方 | $\int\rho^{-1}|\operatorname{div}p+\mu_h\rho u|^2$；汇入 $M_s^2$ 时除以 $s$ |
| $g_-^2,g_+^2$ | 左右端实际 $\int|p\cdot n|^2$，分别积分 |
| $C_{\rm end}$ | $(2\sqrt{s\rho_{\min}})^{-1/2}=0.5664176025785184$ |
| $\gamma$ | 仅作 theory 式(33)–(35)分组诊断的 $2C_{\rm end}^2=0.6416578010215928$ |
| $a_K,b_K,r_K,l_K^0,l_K^1$ | theory 式(33)的插值表示差、散度表示差、原生体缺陷及实际边修正范数 |
| 材料失配平方 | $\mu_h^2\int\rho^{-1}|(\rho-\rho_h)u|^2$；诊断，不重复加到主残差 |

主输出直接按实际通量计算

$$
M_s^2=\|\nabla u-p\|_2^2+s^{-1}\|\rho^{-1/2}(\operatorname{div}p+\mu_h\rho u)\|_2^2,
\quad\eta_{\rm num}=\sqrt{M_s^2}+C_{\rm end}(g_-+g_+),
$$

$$
\tau_{\rm num}=\eta_{\rm num}/U_{\rm num},\qquad
R_{\rm num}=\frac{\tau_{\rm num}}2\left(\tau_{\rm num}+
\sqrt{\tau_{\rm num}^2+4(\mu_h+s)}\right).
$$

这不是 I9.2 的 $2\mu Q/(U-Q)$ 主公式，不要求额外正分母门。
theory 式(34)的 $W$ 仅解释通量表示、原生体缺陷与 lifting，不替代更直接的主 $R$。
上述 $a,b,r,l$ 并非互斥误差或真实误差分解，不能将其各范数简单相加当成已测主贡献。

## 4. 真实材料分类与有限积分预算

本轮以普通双精度实例化理论的局部分类机制，不开发通用认证系统。
各点真实材料按原解析曲线判定；网格标签 $\rho_h$ 仅作比较，不能替代 $\rho$。
曲线弦管用8,192参数段，并使用理论给出的解析二阶导数上界：
中心 $\sqrt{1.86^2+1.76^2}$，每侧 $\sqrt2 R(1+10a)$。
参考三角子片的物理像由二次 Bernstein 控制点包围；只在界面管附近递归四分，最多6层。
未决子片始终保留完整材料候选集合 $\{1,4,17\}$，不按“附近是哪条曲线”缩小集合。
当前实现用解析射线分类：lead有显式径向式，中心用同一原解析曲线求射线交点；
中心可写 $x=A(t)\cos t,y=B(t)\sin t$，$A=0.3+0.06\cos5t$、$B=0.2+0.06\cos5t$，
其极角导数分子至少 $0.24\cdot0.14-0.015>0$，支持单值射线分类。
求射线交点的有限迭代仍需检查残差，不能由理论单值性推断任何迭代都已收敛。
若仅检查本胞元曲线管，必须核对该单元位于其记录胞元及各管不跨胞元边界，
否则应保留相关邻胞元曲线；这一几何剪枝不能缩小未决材料候选集合。

| 项目 | 冻结设置 |
|---|---|
| 局部边矩 | 一维12点Gauss |
| 局部内部矩 | 8×8 Duffy |
| 主评价 | 同一实际通量的10×10 Duffy |
| 积分诊断 | 同一通量同一分片的8×8 Duffy，差值不冒称误差上界 |
| 人工端积分 | 主20点Gauss、16点Gauss诊断；保留实际参数速度 |
| 体平方积分不确定性参考预算 | $1.8\times10^{-7}$ |
| 每端平方范数不确定性参考预算 | $10^{-10}$ |
| 判读 | 达到层数或预算后保留未决数量、面积、积分贡献、材料包络及目标是否满足 |

上述预算若是严格区间宽度且 $U\approx1$，则其理论最大附加 $\eta$ 约为
$\sqrt{1.8\times10^{-7}}+2C_{\rm end}\sqrt{10^{-10}}=0.0004355924$。
$R\le0.01$ 要求 $\tau\le0.004532542821678982$，而 $R\le10^{-4}$ 要求
$\tau\le0.000045371591217607473$。本轮普通材料包络和阶数差并非严格区间，
因此这些是前置工程预算和判读尺度，不是已满足 theory 式(41)的证书。
未决区域的贡献不得置零；主数值与未决材料变化诊断并列。
固定原生场的真实几何失配和积分不确定性必须分开，后者减小不使前者自动消失。
若保存的是未决片候选材料积分的最小/最大值、未单存该片主选材积分，
则用候选宽度对总质量和总加权体项作正负扰动，非负项下端截为零，
按主式单调性传播到 $R$：较小体项配较大质量，较大体项配较小正质量。
这仅是固定求积节点上的材料分类扰动诊断，不包含求积余项、浮点误差或几何证书；
不为了取得更紧的诊断而重跑科学积分。Q8/Q10和端Q16/Q20差异另行报告。
