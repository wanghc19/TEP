# Phase 1 problem framing

本目录只保存 Eigenvalue a posteriori error 专题的范围界定材料。它不是文献综述、
理论主线、论文大纲或数值结论目录。

- `materials.md` 记录只读材料入口及其当前证据地位。
- `questions.md` 记录 Socratic Layer 1 的问题和用户选择。
- `rq-summary.md` 记录已确认的 RQ、初步 FINER 自评和范围边界；它不等于正式方法蓝图。
- `r-da1.md` 记录 Methodology Reflection 末尾的 Devil's Advocate Checkpoint 1。
- `p-method.md` 记录通过 Phase 1 的 Methodology Blueprint 和反证规则。
