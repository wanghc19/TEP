# 2026-11-08 周期波导 BIE／DtN 文献查新归档

`bie-dtn` 指 boundary integral equation（边界积分方程）与 Dirichlet-to-Neumann（DtN）边界映射。Sol 调研的对象是二维无损标量周期波导，目标是在固定切向 Bloch 参数下计算导模频率与场。完整的八项初单、后续补救、实读版本和未查分支见 [[research/explorations/bie-dtn-2026-11-08/evidence|Sol 查新报告]]。归档时只将报告中三处机器本地路径改为仓库相对链接。

**结论（2026-11-08）：在已知文献调研范围内，BIE 特征值求解器这一块未找到尚未解决的有价值问题。** 本轮支持新立项的候选为零，建议在这里结束这轮选题。 这项判断针对所查文献、当前模型以及问题对求解结果的实际影响。Wood 阈值附近的频段覆盖是一项有数据依据的实现限制，留档备查。修正窗口方程有明确的理论疑问，但当前求解器并未采用它。

## 是否扩大查新

就现稿的加边闭合与 Dirichlet 极点而言，现有同模型的 RtR 对照足以判断其贡献边界，建议结束这条查新。若目标仍是寻找独立的 BIE 数值分析课题，可以补一次定向检索。Sol 的不少入口以已知失效机制命名，容易遗漏以线缺陷导模、界面模或色散曲线为题的应用论文。补查时可沿 Fliss 的导模计算及相邻光学文献的引用链，逐篇记录给定量、待求量和作者实际遇到的困难。例如 Fliss 图 7 已含弱局域导模，而 Li–Lu 讨论有限包层中衰减率的相对误差，后者的待求量是复传播常数。两类计算要分别判断。[Fliss，§5](https://arxiv.org/abs/1202.4928) · [Li–Lu，§§I–II](https://personal.cityu.edu.hk/mayylu/papers/shaojie3.pdf)

只有文献明确显示某个困难影响同类波导的导模频率、场或模态识别，后续方法的适用条件仍留下这个具体例子，而且能设计小算例区分现有解法与拟议改进时，才值得进入下一阶段。补查结果见下节。
