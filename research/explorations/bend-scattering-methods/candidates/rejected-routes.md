# 本轮淘汰的散射数值路线

`rejected-routes` 记录此次选题筛选中的失败理由；不是宣称这些研究领域没有价值。证据等级与完整书目见 [[research/explorations/bend-scattering-methods/landscape]] 及独立 [[research/explorations/bend-scattering-methods/review]]。本轮没有运行数值实验。

## 1. 近共振时只估计散射输出，绕开全场病态

**具体目标曾是：** 在远离端口截止的周期两臂质量型Helmholtz问题中，分离近共振子空间与正则补空间，给指定 $S_{ij}$ 的可计算误差；精确BIC（bound state in the continuum，连续谱中的束缚态）处允许场不唯一。

**为什么不单独推荐：** 伴随修正输出、近核消去、第二奇异值稳定界已有Sen等2006年的严格先例；有俘获模但频窗不含阈值时直接算S也已有Plamenevskii–Sarafanov 2014。2026年Lawrence–Yamauchi已有直接散射振幅残差界，Lu–Zhou已有BIC附近增广可逆构造。它们未同时给连续周期端口的所有可计算误差，不代表“拼接这些部件”已有独立创新。

特别不能把名称中的“inf-sup-free”当无条件保证：Chellappa等2023的误差估计含另一个尚未知的误差项；Feng等2024综述再次用逆范数控制该余项。传统有限维truth空间界还不含连续PDE离散误差。

**本轮解析诊断。** 对

$$s_\varepsilon(\omega)=1-\frac{2i\varepsilon^2}{\omega-\omega_0+i\varepsilon^2},$$

实轴上 $|s_\varepsilon|=1$，但在 $\omega=\omega_0$ 将中心错移 $\varepsilon^2$，振幅改变为非零常数量级。故“输出有界”不能推出“输出易算准”，也不能要求任意残差在趋近BIC的材料族上有统一增益。这个有理模型不是原二维正材料PDE的实现定理；连续PDE中的相关敏感性可对照Shipman–Tu 2012的全透射/全反射曲线定理。

可保留为内部工具的内容是：在同一计算中分开记录正则补空间下界、小共振块、端口截断与输出提取误差。若未来发现残差具有额外的结构性消去，可重开问题；本轮没有找到并证明这种额外机制。

## 2. 宽频扫描不漏掉极窄反射峰

**具体目标曾是：** 频率区间内保证 $R(k)\le R_0$，或认证所有相关散射共振已找到。二者并不等价。

**为什么不推荐：** 自适应有理代理、随机sketch、Loewner残差选点、轮廓非线性特征值、认证降阶及有限频带KYP判据已有成熟部件。Pradovera等2025已将BIE逆范数与共振代理连接；Pradovera2023讨论认证与不可计算的输出因子；有限有理系统的全频不等式也不需要新发明。将其接到周期DtN，若没有新的连续误差闭合机制，不足以成为新方法课题。

**有限精度采样的障碍可以精确写出。** 令 $\gamma>0$，

$$r_\gamma(k)=\frac{-i\gamma}{k-k_0+i\gamma},\qquad
t_\gamma(k)=\frac{k-k_0}{k-k_0+i\gamma},\qquad
S_\gamma=\begin{pmatrix}r_\gamma&t_\gamma\\t_\gamma&r_\gamma\end{pmatrix}.$$

实轴上此矩阵互易且酉；上半平面解析且收缩。对避开 $k_0$ 的有限样本，设最近距离为 $d>0$，则 $|r_\gamma(k_j)|,|t_\gamma(k_j)-1|\le\gamma/d$，可低于任意给定数值误差；但 $|r_\gamma(k_0)|^2=1$。这只是否定“有限精度样本加守恒足以给无遗漏保证”的抽象方案，**不否定使用完整算子信息、已知解析半径、线宽下界或可靠轮廓排谱的算法**，也未证明固定PDE族实现所有这些传递函数。

此外，全BIE逆的峰可能来自交换材料问题的伪准共振；Hiptmair–Moiola–Spence 2022已有分析及增广Calderón补救。内部极点可能在某个输入输出中抵消；反射零点与解析背景也影响曲线。因此“数齐离散极点”不能替代连续指定输出的全频保证。

若日后做这个方向，先固定输出与可读取的算子信息，再比较认证降阶/KYP/轮廓方法；不能先假设所有极点已找到，又把不漏检写成成果。

## 3. 极小反射更准确、角度特殊或改透明边界

- 将反射直接从散射场提取，而不是算 $1-T$；增加精度、加密网格、与另一路结果一致：有用的实现改进，但没有独立新机制。
- 若已有 $|r-r_h|\le\eta$，则 $\max(0,|r_h|-\eta)^2\le R\le(|r_h|+\eta)^2$。这个基本传递不是新的可靠性理论；难点在振幅界自身。
- 酉性、互易性只检查结构，不给接近正确S的距离。阈值、倏逝和非正交模式还须使用正确通量形式。
- 蜂窝、120度、拓扑标签不自动产生新数值方法。不能把已有低反射渐近换一个计算器作为本轮主方向。
- RtR/ItI去掉人工Dirichlet极点、Riccati或散射递推避免增长/衰减混合均已有。两局部映射各自稳定不保证其全局匹配逆稳定；真正共振不能靠坐标转换消除。

## 4. 淘汰的含义

本轮没有得到一个值得与阈值候选并列的备选。上述淘汰主要依据强已有方法及错误保证的解析反例，不是“没有搜到好论文”或“实现太难”。如果阈值候选的价值门也失败，合理结论就是本轮尚未筛出可立项的新数值方法，不再为配额改名保留这些路线。
